# 🎨 RGB Color Game

An interactive color guessing game that helps you master RGB color codes while having fun! This web-based game challenges players to identify colors based on their RGB values, improving their understanding of the RGB color model used in web development.

## 🎮 How to Play

1. Look at the RGB color code displayed in the header (e.g., "RGB(255, 0, 0)")
2. Choose the color square that matches the RGB value from the grid of colors
3. If you choose wrong, the square disappears and you can try again
4. If you choose correctly, all squares change to the winning color!

## 🔥 Features

- Three difficulty levels:
  - Easy (3 colors)
  - Medium (6 colors)
  - Hard (9 colors)
- Real-time feedback on your choices
- Responsive design that works on both desktop and mobile devices
- Clean and intuitive user interface
- Dynamic color generation for endless gameplay
- "Play Again" option to start a new game instantly

## 🎨 Color Theory Basics

RGB colors are represented as: `rgb(R, G, B)`
- R: Red value (0-255)
- G: Green value (0-255)
- B: Blue value (0-255)

Examples:
- `rgb(255, 0, 0)` = Pure Red
- `rgb(0, 255, 0)` = Pure Green
- `rgb(0, 0, 255)` = Pure Blue
- `rgb(255, 255, 255)` = White
- `rgb(0, 0, 0)` = Black
